Sar:
---

* sar works like a DVR (Digital Video Recorder) for server performance. It records system resource usage so you can rewind and investigate what happened in the past.

What is sar?

sar stands for System Activity Reporter.

<img width="697" height="410" alt="image" src="https://github.com/user-attachments/assets/12c7e14b-f1a2-4a68-b16e-cea49049f9eb" />

2. Install sysstat
On Amazon Linux / RHEL:
sudo yum install sysstat -y


On Ubuntu:
sudo apt update
sudo apt install sysstat -y


Check installation:
sar -V
