Systemctl:
---------

* systemctl is used to manage services on Linux systems that use systemd.

* For example:
  
      - Start or stop Nginx.
      - Restart Docker.
      - Enable Jenkins at system startup.
      - Check whether SSH is running.
      - Find failed services.
      - Reload systemd after modifying service configuration files.
