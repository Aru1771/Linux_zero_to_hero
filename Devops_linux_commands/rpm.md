rpm -q <package_name> checks whether an RPM package is installed on a Linux system.

It is commonly used in RHEL, CentOS, Amazon Linux and Rocky Linux.

Syntax

    rpm -q package_name


Here:

    - rpm = Red Hat Package Manager.
    - -q = Query.
    - package_name = Package you want to check.
